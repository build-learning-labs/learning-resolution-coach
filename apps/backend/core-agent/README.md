# 🧠 Core Agent Service

The central orchestrator of the learning experience.

## 🚀 Role
- **Planning**: Decomposes learning goals into actionable study plans.
- **Orchestration**: Manages the loop between RAG (context) and the LLM (reasoning).
- **Endpoint**: [http://localhost:8001](http://localhost:8001)

## 🛠️ Tech Stack
- FastAPI
- LLM Adapters (via `shared` package)
- Opik tracing integration
